# 🎬 Cinema Hall Booking System

A complete, production-ready cinema booking system with React frontend and PHP backend.

## ⚡ Quick Start (2 minutes)

### Prerequisites
- XAMPP (Apache + MySQL running)
- Node.js 18+

### Start
```bash
# 1. Verify setup
Double-click DIAGNOSE.bat

# 2. Start dev server
npm run dev

# 3. Open browser
http://127.0.0.1:5173
```
